# 📌 About

LeetPatternTracker is a complete DSA learning and tracking platform built using the MERN Stack. It helps users prepare for coding interviews by organizing DSA questions into Topics and Patterns while tracking progress, maintaining daily streaks, taking notes, bookmarking questions, and providing video resources.

The application also includes an Admin Panel to manage topics, patterns, videos, and questions.
